# 六种策略每周实际进度与期望进度

六种策略画在同一坐标轴，采用蓝、橙、紫、绿、朱红、天蓝六种颜色，并配合不同线型与标记；重合曲线采用不同线宽，不偏移任何数据。横轴为经过周数，每周21时段；纵轴为累计完成工作量。

实际曲线取周末及各自真实完成时点，完成后停止。相邻采样点之间的线段仅用于连接，不表示每个时段均匀工作。期望进度为48×min(t/84,1)，在四周达到48，延期期间保持48。示例环境种子4000000，RL训练种子42，延续作息热图的回放设置，不是100环境的统计均值。

简单循环、优化固定日程与RL前三周的周末样本重合；优化固定日程与RL的完整示例轨迹相同。图中不人为偏移重合曲线。

建议图注：六种策略的每周累计实际工作进度与期望进度。曲线连接周末和实际完成时点，回合完成后停止；期望进度在第28天达到48单位并保持不变。垂直线标记28天目标和35天上限。固定优化日程与示范辅助Q-learning在本示例环境中重合。环境种子为4000000，RL训练种子为42。
