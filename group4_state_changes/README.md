# 六种策略的状态变化

1. six_strategy_fatigue_changes.png／.svg：逐时段疲劳指标，即(100−精力)/100，纵轴以百分比显示。它是精力亏空状态，不是累计透支成本，也不是现实临床疲劳测量。
2. six_strategy_psychological_changes.png／.svg：心情与焦虑两个子图，各含六种策略。心情纵轴0–100，焦虑纵轴0–20以显示本示例中的变化；焦虑变量本身范围仍为0–100。
3. six_strategy_mentor_satisfaction.png／.svg：六种策略的导师满意度，使用阶梯线展示逐时段的离散状态变化。

统一沿用进度图的六种颜色和线型。每个点表示时段结束并完成相应结算后的状态；晚间包含自然恢复，上午／下午不包含。任务完成后停止曲线，不延长、不平滑。横轴是经过天数，单时段为1/3天；第28／35天结束分别是目标／硬期限。

环境种子4000000；RL训练种子42。均为单回合示例，不是100个环境的统计平均。本环境中优化固定日程与RL的逐时段状态完全相同，绘图保留真实重合，没有人为偏移。

程序先重放与评价数据核对的动作序列，再在相同检查种子下获取每个时段的精力、心情、焦虑、导师满意度；逐项核对原slot_logs及终局状态、成本。导师满意度的单回合终值可能不同于论文均值。

所有PNG为400 dpi；疲劳和导师满意度4000×2680，心理状态4000×3600。SVG为矢量版。
state_changes_data.csv／.json为完整逐时段数据；generate_state_changes.py为绘图脚本。完整v2论文未修改。

建议图注：六种策略在同一环境中的状态变化。颜色、线型与前述进度图一致，垂直线标记28天目标和35天硬期限；各曲线于实际回合终止时停止。数据为环境种子4000000的逐时段结算后状态，RL训练种子42；固定优化日程与RL在本示例中重合。
