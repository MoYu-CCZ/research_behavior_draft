## 报告中的RL究竟是什么

本次使用“固定日程示范初始化+在线Q-learning”：先对开发集优化出来的固定日程进行2000回合离策略Q学习，再进行10000回合epsilon-greedy在线学习。三个训练种子为42/43/44，各评估100个环境种子4000000至4000099。

示范阶段的动作来自固定日程；在线学习及评估动作来自agent.choose_action。评估关闭探索，通过当前时间、剩余工作、精力、心情、导师满意度、焦虑等状态查询Q表。它没有读取固定循环脚本，但Q状态包含具体时间，能够记忆示范作息。所有策略共用精力保护。

实际评估中三个RL种子均复现了固定示范的主要行为与成绩。不能将此结果解释为从零自主发现、优于固定作息，或已证明扰动下的自适应能力。此前无示范Q-learning的诊断结果保存在results_grace，但参数已不同，不能作为当前环境中的公平无示范对照。
