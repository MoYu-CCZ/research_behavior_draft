# 六种策略的实际作息热图

文件：six_strategy_schedule_heatmaps.png／.svg，为两行三列组图；fig2a至fig2f为六张独立子图。所有PNG均为400 dpi，组图5600×2480，单图3200×1300。正文和完整v2论文未修改。

深蓝为实验室，中蓝为宿舍，浅蓝为健身房；白色格子为回合结束后未执行。星号为任务完成时段；虚线位于第28天结束处，不是第28天上午。

图注建议：
图2 六种策略在同一仿真环境中的实际作息轨迹。（a）常规固定作息；（b）上午补觉；（c）简单三天循环；（d）优化固定日程；（e）固定日程示范初始化加在线Q-learning；（f）延期低成本循环。横轴为第1至35天，纵轴为上午、下午和晚上，虚线标记28天目标截止点，星号标记完成任务的时段。回合结束后的区域留白。环境种子为4000000，RL训练种子为42；图中展示单回合示例，不是100个环境的统计汇总。

数据来自results_time_aware_v3参数与Q表回放，完成时段及该回合成本均已与evaluation.csv逐行核对。不同环境的成本可能不同，本图没有将单回合成本标为总体均值。

executed_schedule.csv保存实际执行动作；replay_metadata.json保存回放参数和完成情况；generate_heatmaps_blue.py为绘图脚本。运行依赖为项目paper/.figure_deps中的Matplotlib及其依赖；无需重新训练。
